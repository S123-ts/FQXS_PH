# 番茄小说排行榜爬虫（FQXS）

Spring Boot 3.5 + OkHttp 抓取 `fanqienovel.com` 排行榜（男/女频 × 阅读榜/新书榜，37 个子分类），
H2 文件库落库，无框架单页展示与筛选。

> 使用前请先读文末的**免责声明**。

## 运行

```bash
./mvnw -B spring-boot:run
# 打开 http://localhost:8080 → 会先跳到登录页
```

数据落在 `data/fqxs.mv.db`（已 gitignore），启动自动建表并幂等回填历史数据。

### 登录

全站（含所有 `/api/**`）都要先登录，默认凭据写在 `application.yml` 的 `app.auth` 下：
**账号 `admin`，口令 `admin`**。

> **`admin` / `admin` 只是仓库里的占位默认值**：本仓库公开，个人口令不随仓库公开。
> 本机或服务器要用自己的口令，设 `APP_LOGIN_USER` / `APP_LOGIN_PASSWORD` 环境变量覆盖（后者优先）；
> 公网部署必须覆盖并把默认值留空——留空是 fail-closed（登录接口 403、全站拒绝访问）。

## 功能

| 模块 | 说明 |
|---|---|
| **榜单抓取** | 男/女频 × 阅读榜/新书榜 × 37 个子分类；「一键获取全部」每分类抓 70 本，掉榜的书自动清理 |
| **榜单浏览** | 单页无框架，切榜直接读库不重抓；每页 10 本，分类榜与「全部」视图通用 |
| **筛选** | 字数（默认 100 万以上）、状态（默认连载中）、作者性别（默认男作者）、作者评分（默认 9.0），四项都下推 SQL |
| **「新」标识** | 书名后的「新」表示 7 天内首次进榜；判据是入库时间而非最近抓取时间，掉榜后重新上榜重新计时 |
| **拉黑 / 关注** | 按 bookId 全行联动，拉黑默认隐藏、关注默认保留；批量操作串行执行并显示进度，拉黑需二次确认、6 秒内可撤销 |
| **作者信息** | 第三方详情接口补齐作者性别与评分，后台按热度每小时补 60 本，性别只取一次、评分 5 天后刷新 |
| **拉取频道** | 第一行的「全部 / 男频 / 女频」决定后端抓哪些分类，与「展示分类」是两件事——它不改当前列表看什么 |

## 开发

